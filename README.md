# 🦖 DINO GAME

A Chrome Dino-inspired browser game made using HTML, CSS, and JavaScript.

## 🎮 Features
- Jump over obstacles
- Increasing game difficulty
- Score system
- Keyboard controls
- Simple and responsive design

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## ▶️ How to Play
Press the SPACE key to jump and avoid the obstacles.
